# 🚗 SmartDrive

SmartDrive is a vehicle safety and emergency assistance system designed to improve driver safety and provide quick emergency response.

## Features

- 🚗 Vehicle status monitoring
- ❤️ Heart-rate monitoring (mock data)
- 📍 Location monitoring (mock data)
- 👥 Emergency contacts
- 🚨 Accident simulation
- ⏱️ Emergency countdown
- 📢 Simulated emergency notifications
- 📋 Emergency history

## Tech Stack

- React
- JavaScript
- Vite
- CSS

npm install
npm run dev
