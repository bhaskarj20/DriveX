🚗 SmartDrive

Smart Vehicle Safety & Emergency Assistance System

SmartDrive is a web-based prototype designed to monitor vehicle and driver conditions, detect potentially dangerous situations, and assist during emergencies.

✨ Features

- 🚗 Live vehicle simulation
- ❤️ Heart-rate monitoring
- 📊 Real-time sensor graphs
- 🚨 Automatic emergency detection
- 📍 Live location simulation
- 🛡️ Driver risk score
- 📜 Emergency history
- 🤖 AI Assistant
- 🎛️ Emergency & driving simulation controls
- 🌙 Dark mode
- 🔐 Login system

🛠️ Tech Stack

- Frontend: React, JavaScript, Vite
- AI: OpenRouter API
- Styling: CSS
- Deployment: Vercel
- Version Control: Git & GitHub

🌐 Live Demo

https://smart-drive-swart.vercel.app

⚙️ Current Status

SmartDrive is currently a software prototype using simulated vehicle and sensor data.

The system is designed to be extended with real hardware such as heart-rate sensors, GPS, accelerometers, and vehicle sensors in the future.

🚀 Run Locally
